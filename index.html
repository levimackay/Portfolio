AI · Coding Agent · Featured

Lydia

A local, terminal-based coding agent that reads, edits, and tests my code entirely on my own hardware, no API keys, no subscriptions, nothing sent to the cloud. It's open source, and people I've never met have filed bugs against it and sent pull requests to fix them.

Local models on consumer hardware are smaller and slower than frontier hosted models, so Lydia won't be as capable. It's built for personal projects, learning, and situations where "good enough and free" beats "best available and metered."

Challenge
An agentic coding workflow without paying for API usage or sending code to a third party.
Approach
An Ollama-backed agent loop with native tool calling for file edits, git, and shell, plus a verify step that runs my tests before calling a task done. Inference runs on a second machine's GPU over Tailscale. 390 tests run in CI on every push, green across Python 3.11, 3.12, and 3.13.
In the wild
A contributor filed an issue that a config boolean was stored as a string and evaluating truthy, then sent a pull request fixing it. Another added a whole systemd backend so scheduled briefings work on Linux, after the macOS-only version failed on their machine. Both are reviewed and merged, and the systemd one landed with tests covering both backends.

Next.js · Full Stack · Featured

RexNest

A student housing comparison platform for BYU-Idaho renters, built so comparing off-campus options doesn't mean scrolling through five different Facebook groups. It has a contract marketplace, in-app messaging, and moderated reviews with voting and reporting.

The core of it is a value score: a 224-line PL/pgSQL function that ranks every listing 0 to 100 across price, distance, amenities, review quality, management, internet, and rent trend, normalized against the whole dataset. It uses Bayesian-style shrinkage on review scores, so an apartment with two glowing reviews doesn't outrank one with fifty good ones.

Challenge
Comparing off-campus housing means weighing price, distance, amenities, and reviews against each other with no consistent way to score them.
Approach
13 Postgres tables behind Supabase, with 129 lines of row-level security policy and a weighted scoring function that runs set-wise across the table using population min/max normalization, called under security definer with a pinned search path.
Honest gap
No automated tests yet. That's the next priority before building further on top of the marketplace and messaging features.

Python · Typesetting · Featured

Serbo-Croatian dictionary

5,709 entries: 4,047 parsed from a 208-page personal scan, 1,608 folded in from two years of daily word sheets, and 54 added by the pipeline to fill gaps. Typeset into a 301-page, 15-chapter book with zero build warnings.

Challenge
Turning years of handwritten field notes and an old scanned book into something accurate enough to publish, without quietly inventing entries I wasn't confident about.
Approach
1,026 lines of Python across 7 pipeline stages to parse, merge, and enrich entries, including a custom 180-line Markdown-to-Typst compiler, then Typst to typeset the result.
Provenance
Every machine-added field is marked with a degree sign, and that marking is enforced by construction: a machine-supplied field can only reach the page through a wrapper function in the typesetting library that emits the mark, so there's no path that renders one without it. Generated stress marks are checked against their own headword before they're allowed through; nine failed that check and were logged instead of shown.

The provenance rule I wrote to direct this pipeline, and that the pipeline enforces automatically: "If you are not confident, leave it blank. A blank field is honest… We are explicitly optimizing for trustworthiness over coverage. Do not pad."

Python · Education Tooling · Featured

canvas-risk

A risk model that pulls grade and activity data from the Canvas LMS API and scores every student in a course 0 to 100, weighted 40% current grade, 30% missing work, 10% grade trend, 10% recent inactivity, and 10% standing against peers, to surface who's falling behind before it's obvious in the gradebook.

Missing work isn't one flag. A student can be missing an assignment because it's flagged missing, submitted past due, graded as a zero, or marked incomplete, and the model checks all four cases, weighting each by its assignment group so a missed final counts more than a missed quiz.

Challenge
A single flat grade cutoff misses students who are behind on work but still passing, or trending down but not there yet.
Approach
A weighted risk score combining grade, missing work, trend, inactivity, and peer comparison, backed by a compound SQL predicate covering four distinct ways an assignment counts as missing in Canvas's data model. Risk snapshots persist to a database table, and a velocity metric compares the last five snapshots to show whether a student is trending better or worse.
What-if
A simulator decomposes a student's current score, removes one grade component's weighted contribution, substitutes a hypothetical, and reclamps the result to 0 to 100, so an advisor can see what turning in one more assignment would actually do.
Tested
5 unit tests run in CI on every push.
