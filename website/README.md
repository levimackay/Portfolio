# Portfolio Website

The source for my live portfolio at levibmackay.github.io/Portfolio. Built with vanilla HTML, CSS, and JavaScript with no frameworks.

The design uses a glassmorphism aesthetic with blurred card panels over a dark gradient background. The featured card at the top is for SwingOS and the rest of the grid shows the other projects with embedded videos and screenshots directly in the cards.

All media is hosted in this folder alongside the HTML so nothing depends on an external CDN.
