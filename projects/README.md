# Projects

These are the projects with source in this repo. Each one started as a real problem I wanted to solve. Bigger things I've built since — Lydia, RexNest, the Serbo-Croatian dictionary, canvas-risk — live in their own repos and are described on [levimackay.com](https://levimackay.com/).

* [swing-analyzer](swing-analyzer) — webcam tool that watches your head level through a baseball swing (Python, OpenCV, MediaPipe)
* [baseball-database](baseball-database) — MySQL schema and a set of analytics queries built on window functions and CTEs
* [flashcard-app](flashcard-app) — desktop vocabulary tool I built to study Bosnian, Croatian, and Serbian (Python, Tkinter)
* [landscape-estimator](landscape-estimator) — command line estimator for landscaping material and labor costs (Python)
